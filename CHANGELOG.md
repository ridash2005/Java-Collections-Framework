# Changelog

All notable changes to the Java Collection Framework project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-29

### Added
- Initial release of Java Collection Framework educational project by Rickarya Das
- Comprehensive demonstrations of Java Collections API including:
  - Lists: ArrayList, LinkedList, CopyOnWriteArrayList, Vector
  - Sets: HashSet, LinkedHashSet, TreeSet, EnumSet, CopyOnWriteArraySet
  - Maps: HashMap, LinkedHashMap, TreeMap, EnumMap, IdentityHashMap, WeakHashMap, Hashtable
  - Queues: Queue, Deque, PriorityQueue, BlockingQueue, DelayQueue, SynchronousQueue
  - Concurrent Collections: ConcurrentHashMap, ConcurrentLinkedDeque, ConcurrentSkipListMap
- Complete Stream API demonstrations:
  - Intermediate operations
  - Terminal operations
  - Collectors
  - Lazy evaluation
  - Parallel streams
  - Primitive streams
- Advanced topics:
  - Comparable and Hashing concepts
  - Iterator patterns
  - LRU Cache implementation
  - Task submission systems
  - GC concepts
- Professional project setup:
  - Comprehensive README.md
  - MIT License
  - Contributing guidelines
  - GitHub Actions CI/CD pipeline
  - Code of conduct and documentation standards

### Documentation
- Detailed README with project overview and learning path
- Contributing guidelines for future contributors
- CHANGELOG for version tracking
- CI/CD workflow for testing across multiple Java versions
- Code examples and usage demonstrations
