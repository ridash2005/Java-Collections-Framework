# Security Policy

## Supported Versions

We support the latest major version of this project.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Supported       |
| < 1.0   | ❌ Not Supported   |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please follow responsible disclosure practices:

### How to Report

1. **Do NOT** open a public GitHub issue
2. **Do NOT** post the vulnerability on social media
3. Instead, please email security concerns to the project maintainers
4. Include:
   - Description of the vulnerability
   - Steps to reproduce (if applicable)
   - Affected versions
   - Your contact information

### What to Expect

- We will acknowledge receipt of your report within 24 hours
- We will keep you informed of our progress
- We will credit you for responsible disclosure (unless you prefer anonymity)
- We aim to release a patch within 30 days

## Security Best Practices

Since this is an **educational project**, please note:

1. **Production Use**: This code is designed for learning purposes. For production systems, thoroughly test and audit all code.
2. **Concurrency**: While we demonstrate concurrent collections, always validate for your specific use case.
3. **Memory**: Understanding garbage collection is important; monitor memory usage in production.

## General Security Guidelines

- Always use the latest Java version available for your environment
- Keep dependencies updated
- Review code for security implications before using in production
- Test thoroughly in your specific environment
- Follow the principle of least privilege

## Known Limitations

- This is educational code, not production-hardened
- Performance optimizations may not match production standards
- Security hardening beyond educational examples is not implemented
- Custom implementations may not cover all edge cases

## Questions?

If you have security-related questions that are not security vulnerabilities, please:
- Open a Discussion on GitHub
- Email the maintainers
- Review the CONTRIBUTING.md for contact information
